ATELIER 01

Trouver les racines

D'abord un produit nul. Mais que faire lorsque la factorisation ne saute pas aux yeux ?

01 Comprendre

Une racine, c'est quoi ?

Une racine réelle du polynôme P est un nombre réel r tel que P(r) = 0. Commençons par un cas agréable : le polynôme est déjà écrit sous une forme factorisée.

P(x) = 2x² − 8x = 2x(x − 4)

Exemple adapté de ta fiche d'entraînement de Première.

  1. On cherche les valeurs de x qui rendent P(x) nul.
  2. Un produit est nul si, et seulement si, au moins un de ses facteurs est nul.
  3. Donc 2x = 0 ou x − 4 = 0. Les racines sont 0 et 4.

Et sur la courbe ? Pour cet exemple, les racines 0 et 4 sont les abscisses des points (0 ; 0) et (4 ; 0) où la parabole rencontre l'axe des abscisses.

À retenir

Pour résoudre une équation produit nul, on annule séparément les facteurs. On ne divise pas par x sans vérifier qu'il est non nul : on risquerait de perdre la racine 0.

À ton tour · 1 question

Reconnais les racines

Quelles sont les racines de P(x) = x² − 9x + 20 ?

Besoin d'un indice ?

Cherche deux nombres dont la somme vaut 9 et le produit vaut 20, ou vérifie par calcul les valeurs proposées.

01 · Comprendre, deuxième regard

Et si je ne vois aucune factorisation ?

Avec P(x)=ax²+bx+c (a ≠ 0), on peut toujours calculer le discriminant. Il permet de savoir combien il existe de racines réelles, puis de les calculer lorsqu'elles existent. Cette méthode ne dépend pas d’une factorisation « devinée ».

Δ = b² − 4ac
Δ > 0

Deux racines distinctes

Le polynôme s'annule deux fois :

x₁ = (−b − √Δ)/(2a) ; x₂ = (−b + √Δ)/(2a)

Exemple : x² − 5x + 6 : Δ = 1, racines 2 et 3.

Δ = 0

Une racine double

La parabole touche l'axe horizontal en un point :

x₀ = −b/(2a)

Exemple : x² + 2x + 1 : Δ = 0, racine double −1.

Δ < 0

Aucune racine réelle

La parabole ne rencontre pas l'axe horizontal : l'équation P(x) = 0 n'a pas de solution dans ℝ.

Exemple : x² + 2x + 5 : Δ = −16, aucune racine réelle.

À retenir : le discriminant sert d'abord à chercher les racines ; nous le retrouverons ensuite pour étudier le signe du trinôme.

ATELIER 02

Comprendre la forme canonique

Pourquoi écrire un carré ? Pour lire le sommet, l’extremum et les variations presque d’un seul coup d’œil.

02 Comprendre

Pourquoi écrire un carré ?

La forme canonique fait apparaître le sommet de la parabole. Pour P(x) = a(x − α)² + β, ce sommet est S(α ; β).

P(x) = x² − 6x + 10 = (x − 3)² + 1
  1. (x − 3)² est toujours positif ou nul.
  2. Il est nul exactement lorsque x = 3.
  3. Ainsi, P admet le minimum 1, atteint pour x = 3. Le polynôme n'a aucune racine réelle.
Et dans quel sens la fonction varie-t-elle ?

Quand x se rapproche de 3 par la gauche, la distance à 3 diminue : (x − 3)² diminue aussi. Après 3, cette distance grandit : le carré augmente.

↘Décroît jusqu'à 3 S(3 ; 1)minimum : 1 ↗Croît après 3

Donc P est strictement décroissante sur ]−∞ ; 3], puis strictement croissante sur [3 ; +∞[.

Et si le coefficient a est négatif ? Pour a(x − α)² + β, si a > 0, la fonction décroît puis croît : elle admet un minimum. Si a < 0, c'est l'inverse : elle croît puis décroît et admet un maximum. Dans les deux cas, le changement a lieu en x = α.

Et si le carré était multiplié par un nombre négatif ?

Pour Q(x) = −2(x + 1)² + 5, le carré est positif ou nul, mais −2(x + 1)² ≤ 0. Ainsi Q(x) ≤ 5 : la fonction admet un maximum égal à 5, atteint pour x = −1. Elle croît sur ]−∞ ; −1], puis décroît sur [−1 ; +∞[.

Un même sommet, deux sens possibles : ce n’est pas le carré qui change, c’est le signe de a.

Change le signe de a :

Avec a = 1, la parabole est tournée vers le haut : minimum en S(3 ; 1).

Pour x = 3, P(x) = 1 : c'est le minimum.

Choisis la bonne forme

Quelle est la forme canonique de Q(x) = 2x² + 8x + 3 ?

Besoin d'un indice ?

Factorise d'abord par 2 : Q(x) = 2(x² + 4x) + 3. Puis utilise x² + 4x = (x + 2)² − 4.

ATELIER 03

Étudier le signe d’un trinôme

Les racines nous disent où le polynôme s’annule. Et entre ces valeurs, quel est son signe ?

03 Comprendre

Comment connaître le signe d’un trinôme ?

Pour un trinôme P(x) = ax² + bx + c, avec a ≠ 0, chercher les racines ne suffit pas : il peut ne pas y en avoir. Le discriminant permet de distinguer trois situations.

Δ = b² − 4ac
Δ < 0 : aucune racine réelle

Le trinôme garde le signe de a sur ℝ.

Δ = 0 : une racine double

Le trinôme vaut 0 en −b/(2a) et garde le signe de a ailleurs.

Δ > 0 : deux racines distinctes

Il a le signe de a à l’extérieur des deux racines, et le signe opposé entre elles. Il s’annule aux racines.

Sans racine, mais avec un signe !

x² − 6x + 10 = (x − 3)² + 1 > 0 pour tout réel : ici Δ = −4 et a = 1 > 0.

Pour résoudre une inéquation, on étudie d’abord le signe du trinôme, puis on retient les valeurs qui vérifient l’inégalité.

Deux racines : exemple

(x + 2)(x − 5) ≤ 0 possède les racines −2 et 5, avec a = 1 > 0. Le produit est négatif entre elles, nul aux bornes : solution [−2 ; 5].

Attention aux bornes

« ≤ » et « ≥ » incluent les racines ; « < » et « > » les excluent. Si a < 0, les signes sont inversés.

À ton tour · 1 question

Attention au signe « − »

Résous −3(x − 1)(x + 4) < 0.

Besoin d'un indice ?

Diviser par −3 inverse le sens de l'inégalité : (x − 1)(x + 4) > 0. Un produit de deux facteurs du premier degré est positif à l'extérieur de ses deux racines lorsque le coefficient de x² est positif.

Trois réflexes utiles

Il ne s'agit pas d'apprendre trois recettes indépendantes : les racines, la forme canonique et le signe donnent trois regards complémentaires sur un même polynôme.
