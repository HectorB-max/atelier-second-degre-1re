01 Comprendre

Une racine, c'est quoi ?

Une racine du polynôme P est un nombre r tel que P(r) = 0. C'est aussi l'abscisse d'un point où sa courbe coupe ou touche l'axe horizontal.

P(x) = 2x² − 8x = 2x(x − 4)

Exemple adapté de ta fiche d'entraînement de Première.

  1. On cherche les valeurs de x qui rendent P(x) nul.
  2. Un produit est nul si, et seulement si, au moins un de ses facteurs est nul.
  3. Donc 2x = 0 ou x − 4 = 0. Les racines sont 0 et 4.
À retenir

Pour résoudre une équation produit nul, on annule séparément les facteurs. On ne divise pas par x sans vérifier qu'il est non nul : on risquerait de perdre la racine 0.

02 Comprendre

Pourquoi écrire un carré ?

La forme canonique fait apparaître le sommet de la parabole. Pour P(x) = a(x − α)² + β, ce sommet est S(α ; β).

P(x) = x² − 6x + 10 = (x − 3)² + 1
  1. (x − 3)² est toujours positif ou nul.
  2. Il est nul exactement lorsque x = 3.
  3. Ainsi, P admet le minimum 1, atteint pour x = 3. Le polynôme n'a aucune racine réelle.
Et dans quel sens la fonction varie-t-elle ?

Quand x se rapproche de 3 par la gauche, la distance à 3 diminue : (x − 3)² diminue aussi. Après 3, cette distance grandit : le carré augmente.

↘Décroît jusqu'à 3 S(3 ; 1)minimum : 1 ↗Croît après 3

Donc P est strictement décroissante sur ]−∞ ; 3], puis strictement croissante sur [3 ; +∞[.

Et si le coefficient a est négatif ? Pour a(x − α)² + β, si a > 0, la fonction décroît puis croît : elle admet un minimum. Si a < 0, c'est l'inverse : elle croît puis décroît et admet un maximum. Dans les deux cas, le changement a lieu en x = α.

Pour x = 3, P(x) = 1 : c'est le minimum.

À ton tour · 1 question

Choisis la bonne forme

Quelle est la forme canonique de Q(x) = 2x² + 8x + 3 ?

Besoin d'un indice ?

Factorise d'abord par 2 : Q(x) = 2(x² + 4x) + 3. Puis utilise x² + 4x = (x + 2)² − 4.

03 Comprendre

Quand le produit est-il négatif ?

Pour résoudre une inéquation, on repère les racines, puis on étudie le signe des facteurs sur les intervalles qu'elles délimitent.

(x + 2)(x − 5) ≤ 0
  1. Les valeurs qui annulent le produit sont −2 et 5.
  2. Entre ces deux valeurs, les facteurs sont de signes contraires : le produit est négatif.
  3. On cherche « ≤ 0 » : on inclut donc les deux racines. Solution : [−2 ; 5].
Attention aux bornes

« ≤ » ou « ≥ » inclut les zéros ; « < » ou « > » les exclut. Si un coefficient négatif multiplie le produit, son signe est inversé.

À ton tour · 1 question

Attention au signe « − »

Résous −3(x − 1)(x + 4) < 0.

Besoin d'un indice ?

Diviser par −3 inverse le sens de l'inégalité : (x − 1)(x + 4) > 0. Un produit de deux facteurs du premier degré est positif à l'extérieur de ses deux racines lorsque le coefficient de x² est positif.

Trois réflexes utiles

Il ne s'agit pas d'apprendre trois recettes indépendantes : les racines, la forme canonique et le signe donnent trois regards complémentaires sur un même polynôme.
